Задача 2: Кэширование API Данных с Помощью Dexie

Описание:

Разработайте веб-приложение, которое получает данные о продуктах из внешнего API и кэширует их в IndexedDB с использованием библиотеки Dexie для обеспечения оффлайн-доступа.

Инициализация базы данных с Dexie:

Имя базы данных: ProductDatabase

Версия: 1

Объектное хранилище: products

primary key: id

Индексы:

category

price

Получение данных из API:

Используйте публичный API для получения списка продуктов (например, Fake Store API).

При первом запуске приложения загрузите данные из API и сохраните их в IndexedDB.

При последующих запусках сначала загрузите данные из IndexedDB, а затем обновите их из API в фоне.

Отображение данных:

Показывайте список продуктов с возможностью фильтрации по категории и сортировки по цене.

Реализуйте поиск по названию продукта.

Оффлайн-доступ:

Обеспечьте работу приложения в оффлайн-режиме, используя кэшированные данные из IndexedDB.

Обновление данных:

Добавьте кнопку для ручного обновления данных из API.

При обновлении отображайте уведомление о статусе операции.

Требования:

Используйте Dexie для работы с IndexedDB, включая инициализацию базы данных, добавление и получение данных.

Реализуйте обработку ошибок при запросах к API и операциях с IndexedDB.

Используйте async/await для управления асинхронными операциями.

Обеспечьте отзывчивый интерфейс, который корректно отображает данные и состояние приложения.

Дополнительные Условия:

Реализуйте механизм проверки обновлений данных и синхронизации с IndexedDB.

Используйте индексы для эффективного поиска и фильтрации продуктов.
