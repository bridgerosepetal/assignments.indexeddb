Задача 3: Управление Заказами в Приложении E-commerce

Описание:

Создайте модуль управления заказами для веб-приложения электронной коммерции, используя IndexedDB и Dexie. Модуль должен обеспечивать хранение информации о заказах, связывать их с пользователями и продуктами, а также предоставлять возможности для анализа данных.

Инициализация базы данных:

Имя базы данных: ECommerceDB

Версия: 1

Объектные хранилища:

users

keyPath: id (autoIncrement: true)

Индексы: email (уникальный)

products

keyPath: id (autoIncrement: true)

Индексы: category, price

orders

keyPath: orderId (autoIncrement: true)

Индексы: userId, productId, orderDate

Добавление данных:

Функции для добавления пользователей, продуктов и заказов.

При добавлении заказа связывайте его с существующими пользователями и продуктами.

Просмотр заказов:

Отображение списка заказов с информацией о пользователе и продукте.

Возможность фильтрации заказов по дате, пользователю или категории продукта.

Анализ данных:

Реализуйте функцию для получения статистики, например:

Количество заказов за выбранный период.

Топ-5 самых продаваемых продуктов.

Пользователи с наибольшим количеством заказов.

Обновление и Удаление:

Возможность обновления информации о заказах.

Возможность удаления заказов с подтверждением действия.

Требования:

Используйте Dexie для работы с базой данных, включая создание объектных хранилищ и индексов.

Обеспечьте целостность данных при добавлении и обновлении заказов с помощью транзакций.

Реализуйте эффективные запросы с использованием индексов для фильтрации и анализа.

Предоставьте интерфейс для взаимодействвия с данными (можно использоать простые формы и таблицы).

Дополнительные Условия:

При удалении пользователя или продукта учитывайте зависимость заказов и обеспечьте соответствующую обработку (например, каскадное удаление или предупреждение пользователя).

Оптимизируйте запросы для получения статистических данных, используя методы Dexie для группировки и агрегации, если это возможно.
