Задача 1: Создание и Управление Базой Данных Пользователей

Описание:

Создайте веб-приложение, которое использует IndexedDB для хранения информации о пользователях. Приложение должно предоставлять следующие функции:

Создание базы данных:

Имя базы данных: UserDatabase

Версия: 1

Объектное хранилище: users

keyPath: id (autoIncrement: true)

Индексы:

name (не уникальный)

email (уникальный)

Добавление пользователей:

Форма для ввода имени и email.

При добавлении проверять уникальность email.

Просмотр списка пользователей:

Отображение всех пользователей в таблице.

Возможность фильтрации по имени с использованием индекса.

Обновление информации пользователя:

Возможность редактирования имени и email существующего пользователя.

Обновление должно проверять уникальность нового email.

Удаление пользователя:

Кнопка для удаления пользователя из списка.

Обработка ошибок:

Отображение сообщений об ошибках при попытках добавить пользователя с существующим email или другие ошибки операций.

Требования:

Реализуйте операции с использованием чистого IndexedDB (без библиотек).

Используйте транзакции для обеспечения целостности данных при добавлении и обновлении.

Обеспечьте асинхронность операций с помощью промисов или async/await.

Дополнительные Условия:

После успешного добавления, обновления или удаления данных обновляйте отображение списка пользователей без перезагрузки страницы.

Используйте курсоры для перебора всех пользователей при отображении списка.
